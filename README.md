# ISRA 光学质量分析工具

适用于 ISRA FAULTFINDER 无表头 `.zone.csv` 总表。Python 3.10+，无需安装第三方依赖。

```bash
cd /workspace/ISRA-Analysis
python server.py --port 8765
```

在运行工具的电脑上用浏览器访问 `http://127.0.0.1:8765`。服务只监听本机；云环境没有自动发布公共网页。也可以下载仓库，在本地电脑用同样命令运行。

1. 同时选择总表和对应品种的 XML / DFQ。支持多天、多品种合并。
2. 筛选品种、分区、检测项目、日期与 Max / RoC。
3. 在公差管理中核对公差，可补充当前品种的上下限并应用。可导出 JSON 保存配置，下一次重新导入。
4. 查看设备合格率、重新判定的超差片数、公差覆盖率、项目统计和趋势；导出筛选明细和统计 CSV。

## 数据解释与限制

总表每行前 7 列：时间戳、日期、时间、玻璃 ID、Program ID、品种、整片 +/-。之后每 8 列：完整分区项目、分区 +/-、Max、Max X、Max Y、RoC、RoC X、RoC Y。不同记录允许不同分区数量。不符合格式的行单独报告，不计入统计。仅含 `Zone,Blob-Nr.,Area,Quality,max. Optic` 表头的 CSV 不是此总表。

公差按品种名称、完整分区项目和指标匹配；同名但不同 Program ID / 配方版本应先区分名称，不能直接合并判定。当前不按生产线或生效日期自动管理公差版本，请每次导入匹配的配方。XML A/B 含义不能从字段名可靠推出，因此只导入 A/B 相同的正值作为对称上下限；不相同则拒绝并要求使用有明确上下限的 DFQ 或手动配置。DFQ 使用 K2112/K2113。XML 导出的编码声明与实际字节不一致已兼容。重复公差相同则合并，不同则拒绝。DISTORTION2 的零 RoC 无配置时视为不适用。

Max 是带符号极值，判定为 lower <= value <= upper；不使用绝对值替代显式上下限。缺少公差标为未配置，绝不默认为合格。整片设备合格率保留原始判定，重算超差片数仅覆盖当前筛选指标，不代表全部项目的最终放行结论。不同品种的数值分组统计。没有面形网格数据，坐标仅用于追溯极值，不从截图猜测分区边界或生成伪热图。

重复身份（品种、程序、时间戳、玻璃 ID）提示后保留。导入的数据只存在当前网页内存，刷新会丢失；服务器不保存上传内容、不使用外部服务。公差编辑后需点击应用。导出 CSV 对表格公式起始字符添加文本前缀。
